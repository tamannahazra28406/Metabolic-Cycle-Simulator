# Metabolic-Cycle-Simulator
This is a Python-based simulation toolkit that models human metabolic cycles as systems of ordinary differential equations. It covers nine core pathways: Glycolysis, Gluconeogenesis, Glycogenesis, Glycogenolysis, Beta-oxidation, the TCA (Krebs) cycle, the Pentose Phosphate Pathway, Ketogenesis, and the Urea cycle.
